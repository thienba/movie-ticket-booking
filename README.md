# movie-ticket-booking

A cinema ticket booking website with an admin area, built in React against a practice cinema API from a training course.

## Features

- **Customers:** browse movies and showtimes by cinema, see movie details, pick seats and check out, register, log in, and see past bookings in the profile
- **Admin:** manage users and movies (add, edit, delete) and create showtimes
- Vietnamese and English (i18next), carousel of now-showing movies

## Stack

React, Redux with Redux-Thunk, React Router, Formik, Ant Design, Tailwind CSS, Axios, i18next, Moment.

## Run

```bash
npm install
npm start          # http://localhost:3000
```

The API address and group code are in `src/utils/settings/config.js`.
